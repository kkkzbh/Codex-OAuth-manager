# Codex OAuth Manager v0.0.1

Initial public release for `CodexBar Accounts`.

## What's included

- `CodexBar Accounts` Plasma 6 widget.
- Prebuilt `codexbar-collector` for Linux x86_64.
- Accounts bridge script for Plasma.
- One-command installer with dependency prompts for `dnf`, `apt`, and `pacman`.

## Install

```bash
curl -fsSL https://github.com/kkkzbh/Codex-OAuth-manager/releases/latest/download/install.sh | bash
```

The installer requires Linux x86_64, KDE Plasma 6, `kpackagetool6`, and a `codex`
command in `PATH`. You do not need to be logged in before installing; the widget
can launch `codex login`.

## Notes

- The public release only includes `CodexBar Accounts`.
- `CodexBar Tokens` is not part of this release.
- `CodexBar Workers` has been removed.
- The Plasma widget ID changed from `local.codexbar.accounts` to
  `com.github.kkkzbh.codex-oauth-manager.accounts`. The installer does not
  remove the old ID automatically, to avoid changing existing panel layouts.
- KDE Store packages only cover the Plasma widget frontend. Full functionality
  requires installing the GitHub Release backend with the installer above.
